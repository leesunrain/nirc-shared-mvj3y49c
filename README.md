# 슬기로운 마루타 생활 v11 — Garmin 정밀 분석 강화

## 주요 변경
- 앱 제목과 설치 이름을 **슬기로운 마루타 생활**로 변경.
- Garmin 이미지 최대 10장 및 기존 iPhone 사진 업로드 지원 기능 유지.
- AI 판독 후 **입력 수치별 근거, LT1·LT2 훈련 자극과 현재 상태, 반복·회복, 과거 유사 훈련 비교, 다음 훈련 제안, 불확실성**을 긴 보고서로 표시.
- AI 분석 내용은 훈련 메모에 자동 추가되며 **훈련 저장**을 눌러야 데이터베이스에 저장됨. 기존 기록은 삭제하지 않음.
- LT1/LT2는 젖산 측정 없이 확정하지 않고 근거가 부족한 경우 판단을 보류함.

## 배포
- **기존 Vercel 프로젝트**에 ZIP을 배포하세요. 다른 프로젝트를 새로 만들면 환경변수가 공유되지 않습니다.
- AI 분석은 해당 프로젝트에 `OPENAI_API_KEY`가 등록되어 있어야 합니다. API 요금은 별도입니다.
- 기존 Supabase 연결 정보 및 선수 번호/등록코드 방식 유지.
- 배포 후 iPhone과 Android에서 1장 및 여러 장 분석, 입력값/보고서/저장을 실제 테스트하세요.
- AI 보고서는 참고 자료입니다. 의학적 진단이나 실제 젖산역치 측정값이 아닙니다.

## v11 변경사항
- 훈련 기록 화면 하단의 고정 API 키 안내 배너 제거.
- 분석 실패 시에만 오류 메시지 표시.
